# Security policy

FrostIDE opens local listeners (the Claude Code IDE bridge, MCP and helper pipes) and runs project tooling,
so security reports matter even for a personal project.

Report vulnerabilities privately to the repository owner (frosty@frostys.tech) instead of opening a public
issue. Include the version or commit, the platform and a reproduction. Expect an acknowledgement within a week.

Design rules for listeners and untrusted projects are in PLAN.md sections 3.5 and 5.2.
